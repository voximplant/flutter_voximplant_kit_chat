# Changelog

### 1.2.0
- Updated Android and iOS platform code to use Voximplant Android Kit Chat UI SDK 1.5.0 and Voximplant iOS Kit Chat UI SDK 1.7.0
- Added support for the KitChatRegion.mx region
- iOS: removed FlutterFramework from SPM dependencies to fix application build issues on Flutter versions below 3.41

### 1.1.0

New:
- Compatibility with Flutter 3.44/Dart 3.12 and built-in Kotlin
- Updated Android and iOS platform code to use Voximplant Android Kit Chat UI SDK 1.4.0 and Voximplant iOS Kit Chat UI SDK 1.6.1

Fixes:
- Fixed a build warning on iOS if SPM is enabled

### 1.0.0

- Initial public release of the Voximplant Kit Chat SDK for Flutter.
